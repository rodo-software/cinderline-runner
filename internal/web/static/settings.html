Connecting

Settings

What holds for all projects of this runner. A project's own parallel runs and transcript days, set on its page, win over these.

Strict host blocking

When on, a person's answer in Cinderline cannot open a host the egress proxy refused: only the hosts allowed here, for all projects, or on a project's page can. When off, a person can open a host for one issue's runs in Cinderline.

Hosts for all projects

The hosts the runs of every project may reach.

Skill packages for all projects

The skill packages the runs of every project may load with strict hosts on.

Parallel runs

How many runs of one project may run at once, unless the project sets its own.

1 to 10.

Transcripts

What the runner keeps of each run for the Runs page: its steps, prompts and the agent's output.

0 to 365, unless a project sets its own. 0 keeps nothing after a run ends.

The most disk all transcripts take, such as 512m or 2g; the oldest go first.

Web page

1024 to 65535. After a change this page answers only at the new address.

Set in config.json

These have no command: they are set in the runner's config.json.
