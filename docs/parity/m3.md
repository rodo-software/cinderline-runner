# M3 parity: the old suite's cases

Plan M3, "Done when": every ported test passes against the fakes, and the old suite's cases are ticked off in a table. This file is that table (CSR-28).

**Source.** The `node --test` suites of the app repository's `runner/` at commit `ecde51a` (2026-11-06), which M3 ported from instead of `legacy/` (decision 2026-11-05-legacy-reference, amendments). Only case names are cited here. Template-literal names (`${…}`) are one row each; their variants are covered by the Go tests named.

**Status:**

- **Ported:** a Go test in this repository ports it and passes against the fakes.
- **M4 (CSR-x):** the case tests a real `Forge`, `Client` or `Environment` implementation, which M4 builds with the issue named. The M3 side (the fake answers it) is named where there is one.
- **Dropped:** a decision removed the behaviour.
- **Replaced:** the new design has no such code; the reason is given.
- **Missing:** not ported in M3, and the plan's M3 list does not name it. Willem decided these are part of parity (decision 2026-11-06-m3-parity-gaps); each row names the backlog issue that ports it.

## Notes for the review

1. **What differs on purpose** (plan M3) is the only behaviour change in the ported tests: paused notes in the host state folder (`run.TestPausedDirIsPerProject`), agent labels in the token instead of on comments (see the reclaimed-parent row), and the `cinderstack/` branch prefix (`run.TestPublishPushesTheIssueBranch`). Writer teams are gone by a later decision (2026-11-06-no-writer-teams), and the prompt order follows decision 2026-11-06-prompts.
2. **Workers skip the project files.** Legacy's `agentEnv` sets `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` or `OPENCODE_DISABLE_PROJECT_CONFIG=1` for agents without CinderStack access (the app repository's decision 2026-11-05-workers-skip-project-files). The orchestrator prompt's half is ported. The environment half belongs to CSR-33 and CSR-34; their texts predated that decision, so CSR-28 added it to both (decision 2026-11-06-m3-parity-gaps).
3. **Beyond the legacy suites**, the M3 issues also port branches of `runner.mjs` that no legacy test reaches (attempts, the merge wait's outcomes, sub-issue edges); those tests are not listed here.
