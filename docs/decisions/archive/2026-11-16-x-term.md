# golang.org/x/term for hidden input

- **Status:** Accepted
- **Date:** 2026-11-16
- **Source:** Willem asked for hidden token input in `cinderline key set` after `manage` (and its `charmbracelet` dependencies) was removed.

## Decision

`key set` reads a secret with `term.ReadPassword` when stdin is a terminal, and as a plain line otherwise (pipes, scripts).

## Reason

The standard library cannot turn off terminal echo, and doing it by hand needs separate code for Unix and Windows. `golang.org/x/term` is maintained by the Go team and depends only on `golang.org/x/sys`, which the keychain library already brings in.
