# Decisions

Binding decisions Willem made for the runner, each with its reason. One file per decision or per batched round of questions, named `YYYY-MM-DD-topic.md` and referred to as `decision YYYY-MM-DD-topic`. Records in the Cinderline app repository are referred to by their name there (numbered up to 0122, dated after that); they are not copied here.

Each record has: Status, Date, Source (who decided, which issue), Decision, Reason.
