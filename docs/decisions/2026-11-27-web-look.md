# Decision 2026-11-27-web-look

- **Status:** Accepted
- **Date:** 2026-11-27
- **Source:** Willem on CLR-314 (the redesign of the mock pages), answers to two questions.

## Decision

1. **What each page is for, in order.** First "does anything need me?": a glance that all is well, or the one thing to fix. Second, following a live run: its current step and what the agent does now. Setup and finished runs come after, one click down.
2. **The look is calm and mostly unboxed.** This amends the line "The look follows Syncthing: a top bar, panels, clear status colours" of decision 2026-11-26-local-web-page. The top bar and the clear status colours stay. The boxed panels with grey headers go. Each page opens with its name and one status line in plain words, then what needs you, then what runs now; the rest are rows that fold open, separated by whitespace and thin rules. Only something that needs you is drawn in a box.
3. **Written for ADHD readers.** One column and the same order on every page, one focal point at the top, a fold's summary line already says the main fact, short labels, larger type with room around it, nothing that moves on its own (no pulsing dot), and colour only for status and actions.
4. **A light and dark switch in the top bar.** The page follows the system until the switch is used; the choice is kept in that browser only (`localStorage`).

## Reason

1. The runner works unattended, so the common visit is a check for trouble, and the next most common is watching a run. In the first mocks every fact had the same weight, so the one that needed attention had to be searched for.
2. Many boxes of equal weight are visual noise and fight "one thing first", the more so for a reader with ADHD.
3. Willem asked for a switch to compare both themes easily.
