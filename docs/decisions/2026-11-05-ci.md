# Where CI runs: Linux on Forgejo, macOS, Windows and the snapshot build on GitHub

- **Status:** Accepted
- **Date:** 2026-11-05
- **Source:** Decided by Willem on CSR-5; proposed by Claude.

## Decision

- Linux CI (gofmt, vet, staticcheck, race tests, govulncheck) runs on Forgejo at git.rodo.nl, with `runs-on: docker`.
- macOS and Windows checks and the GoReleaser snapshot build run on GitHub Actions.
- The release stays on GitHub Actions, so the attestations of decision 2026-11-05-runner-rewrite-details item 16 still hold.
- GitHub is the public home for source and outside issues.
- Agents got a one-time permission on CSR-5 to write the two workflow files (`.forgejo/workflows/ci.yml`, `.github/workflows/ci.yml`); after that the rule in AGENTS.md applies again.

## Reason

- Forgejo has no hosted macOS or Windows runners.
- Attestations exist only for builds in GitHub Actions; signing elsewhere means managing a key.
- Pull requests from outside contributors on GitHub still get CI on macOS and Windows; their Linux checks need a manual copy to Forgejo.
